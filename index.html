Content architecture: Linear (predefined sequence), Grid (two or more dimensions), Hierarchical (hypertext links can lead horizontally across vertical branches). Navigation: individual link, horizontal bar, vertical column, tabs, site map. (Slides 18-20)

3. Cookies and web cachesتعريفرسم

Cookies maintain state between transactions. Four components: cookie header line in the response, cookie header line in the next request, cookie file on the user host managed by the browser, back-end database at the site. (Slide 14)

Uses: authorization, shopping carts, recommendations, session state. First-party cookies track behavior on one site; third-party cookies track across sites. (Slide 16)

Web cache goal: satisfy client requests without involving the origin server. If the object is in the cache it is returned, else the cache requests it from the origin server, stores it and returns it. Benefits: shorter response time, less traffic on the access link. (Slides 17-18)

ببساطةأول زيارة: الموقع يبعت set-cookie بـ ID (مثلًا 1678)، وفي كل زيارة بعدها المتصفح يبعت cookie: 1678 فالموقع يعرفك (Slide 15).
اتلخبط فين؟الـ cookie مش بتتخزن في السيرفر بس: فيه نسخة عند المتصفح وسجل في الـ database.

4. FTP and e-mailمقارنةاختيار من متعدد

FTP: client/server model, server port 21 for the TCP control connection (authorization, commands) and port 20 for the TCP data connection; the server opens a data connection per file and maintains state (current directory, authentication). (Slides 19-20)

FTP commands: USER, PASS, LIST, RETR (get file), STOR (put file). (Slide 21)

E-mail has three major components: user agents, mail servers, and SMTP. SMTP is used between mail servers; the sending server is the client and the receiving server is the server. A mail server holds user mailboxes and an outgoing message queue. (Slides 22-23)

5. DNS and video streamingتعريفاختيار من متعدد

DNS is a distributed database implemented in a hierarchy of name servers, mapping host names to IP addresses. To resolve www.amazon.com: root server, then .com TLD server, then amazon.com authoritative server. (Slides 25-26)

Video streaming: major consumer of bandwidth; challenges are scale and heterogeneity; solution: distributed, application-level infrastructure. Video is a sequence of images at a constant rate; coding uses spatial redundancy (within an image) and temporal redundancy (differences between frames). Challenges for stored video: varying bandwidth, packet loss and delay. (Slides 27-29)

ببساطةDNS = دليل التليفونات: بتسأل عن الاسم وياخد منك الرقم (الـ IP). Spatial = توفير داخل الصورة الواحدة، Temporal = ابعت الفرق بين الفريمات بس.

FTP flow: client contacts the server at port 21 over TCP; authorization is done over the control connection; commands (LIST, RETR, STOR) go over control; for each file transfer the server opens a TCP data connection and closes it after one file.

11. Processes and sockets in detailتعريفاختيار من متعدد

Process: a program running within an end system. Within the same host, two processes communicate by inter-process communication defined by the OS; processes in different hosts communicate by exchanging messages. The client process initiates communication; the server process waits to be contacted. (Slide 7)

The socket is the software interface through which a process sends and receives messages; the application developer controls the process, while the operating system controls TCP with buffers and variables underneath the socket. (Slide 8)

Q: does the IP address of the host suffice to identify the process? A: no, many processes can run on the same host; the identifier includes the IP address and the port number. (Slide 9)

ببساطةعلى نفس الجهاز: العمليات تكلم بعض عن طريق الـ OS. بين جهازين: بتتبادل رسائل عبر الشبكة.

13. Mail message, DNS and streaming: extra detailsتعريفاختيار من متعدد

Mail message format (Slide 24): header lines (To:, From:, Subject:), a blank line, then the body, which is the message in ASCII characters only. These header lines inside the message are different from the SMTP commands MAIL FROM: and RCPT TO:.

DNS (Slide 25): people have many identifiers (SSN, name, passport number); Internet hosts and routers have an IP address (32 bits) used for addressing datagrams and a name (e.g. cs.umass.edu) used by humans. DNS is a distributed database implemented in a hierarchy of many name servers.

Streaming stored video, simple scenario (Slide 29): a video server stores the video and sends it across the Internet to a client. Main challenges: server-to-client bandwidth varies over time with changing congestion levels; packet loss and delay due to congestion delay playout or reduce video quality.

Spatial coding example (Slide 28): instead of sending N values of the same colour (all purple), send two values: the colour value and the number of repeated values N. Temporal coding example: instead of sending the complete frame i+1, send only the differences from frame i.
